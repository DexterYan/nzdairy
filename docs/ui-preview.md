## Visual Direction

- Warm off-white page background with dark forest-green text.
- White cards with restrained borders and generous spacing.
- Large price and revenue figures; supporting metadata remains visible but quiet.
- Desktop uses two comparison cards and three scenario columns.
- Mobile stacks comparison and scenario cards vertically.
- Warnings use both text and an icon or border treatment, never colour alone.
